Institutional SSO Access

Session Status

Not Connected

How it works:

  1. Click Start SSO Login to open your institution's login page in a headed browser.
  2. Complete authentication manually (username, password, MFA).
  3. Click Continue when finished. The system will never access what you type.
  4. Tier 3 and 3.5 retrieval will use your authenticated session.

If your session expires (403 errors), click Re-authenticate to start fresh.

Configuration

SSO URLs are configured in the Settings panel. At least one must be set for Tier 3 retrieval.
